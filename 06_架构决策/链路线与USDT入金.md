# DramaX 架构决策记录：链路线与 USDT 入金

> 适用版本：V2.1 · 2026-08-28 · 决策状态：已定调（待正式评审）

## 一、链路线决策

### 结论
现阶段**不上公链**：版权用联盟链存证（蚂蚁链/至信链/长安链），Drama/生态积分走中心化 DB 账本。海外发行成熟后迁 **BSC**。

### 三条路线对比

| 路线 | 做法 | 结论 |
|---|---|---|
| A. 国内合规（当前） | 联盟链版权存证 + DB 账本；Drama 叫"权益值"不叫代币 | 唯一能落地且合规的起步路线 |
| B. 海外发行 | Drama→BEP-20，权益→NFT，积分/GIP 链下 Points | 合规成果归零，监管靶心 |
| C. 全上链 | 每笔 P2P 上链 | 高频微支付手续费/延迟不可接受，否决 |

### BSC 迁移方案（预留，暂不执行）
- **资产分层**：Drama → BEP-20；剧本权益 → ERC-1155/721；生态积分与来源B奖励**永远链下**。
- **P2P 改造**：手工放行 → 合约托管自动交割（Escrow：买家锁 USDT → NFT 自动过户 → 卖家提款），消灭假凭证/申诉场景。
- **抢购防抢跑**：Commit-Reveal 或抽签制；预约 Drama 由合约托管。
- **结算返佣**：70/15/15 结算瀑布写分账合约；10 代返佣用 Referral Registry（链上天然幂等）。
- **定价不上链**：日增 2%/3%、复利规则留在链下（保留调整弹性），链上只记成交价。
- **基建**：AA/MPC 内嵌钱包、BNB relayer 代付 gas、合约审计（CertiK/TierN）。
- **两个代价**：规则弹性归零（上链前必须冻结全部待确认规则）；合规不因上 BSC 豁免。
- **节奏**：先链下 MVP 验证闭环（结算引擎按分账合约逻辑写、持仓表按 ERC-1155 字段设计），规则冻结后一次迁移，不做半上链中间态。

## 二、USDT 入金方案（已写入 V2.1 第 16 节）

### 锚定与计价
- **1 Drama = 1 USDT**（原 ¥1 锚定作废），全场 USDT 计价，人民币仅 UI 展示换算。
- 15% 现金收益出金 = USDT 提现；P2P 收款方式 = USDT 地址。

### 入金流程
1. KYC 后生成专属充值地址（地址池派生 + 归集）。
2. 转入 USDT → 链上确认（TRC-20 ≥19 确认 / BSC ≥15）→ 合约白名单校验防假币 → Drama 1:1 入账。
3. usdt_deposit 流水：txid（唯一索引）、网络、地址、金额、确认数。
4. 热钱包阈值归集冷钱包；平台私钥 MPC/多签。

### 出金流程
KYC + 风控审核 → 冷钱包审批签发 → 链上转账；提现手续费/最小额配置化；大额（>10,000 USDT）人工复核。

### 风控
- 链上分析（Chainalysis/TRM）：黑名单地址、混币器关联资金拒收/冻结。
- 黑 U 风险：TRC-20 USDT 存在 Tether 冻结风险；出入金实名一致。
- 假充值防护：仅认可白名单合约（TRC-20: TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t / BSC: 0x55d398326f99059fF775485246999027B3197955）。

### 合规定性（关键）
- 平台收 USDT = 直接接触虚拟货币，不再是纯链下积分模型。
- 中国大陆用户：9.24 红线，必须区域屏蔽 + 海外主体运营。
- 海外运营：按辖区评估 VASP/MSB 注册、税务与支付合规。

### 新增待确认规则（并入 V2.1 第 14 节）
1. 充值网络选择（TRC-20 / BSC-20 / 双支持）
2. 提现手续费与最小额
3. 是否引入第三方托管/支付网关（Fireblocks、Transak 等）
4. 大额复核阈值

## 三、生态积分合并决策（V2.0 → V2.1）

- GIP + 资产积分 → **生态积分**（单一账本，来源 A 交易产出 / 来源 B 行为奖励）。
- 三条铁律：积分不可兑回 Drama（防闭环杠杆）；来源 B 计入统一预算池设年度上限；积分保持链下不代币化。
