## 关键决策记录（时间线）

1. **项目更名**：短剧剧本交易平台 → DramaX（文档标题/页脚已改，DAO → Drama 全文替换）。
2. **积分合并**：GIP + 资产积分 → 生态积分（来源 A/B，统一预算池，禁 Drama 回路，转换 1:1）。
3. **链路线**：先联盟链版权存证 + DB 账本；BSC 迁移预留（Drama BEP-20 + 权益 NFT + 托管交割），积分永远链下。
4. **入金**：USDT 入金/出金，1 Drama = 1 USDT，P2P 凭证改 txid 自动核验；合规定性升级为涉虚拟货币业务（海外主体 + 区域屏蔽）。
5. **UI 原型**：团队 software-dramax 产出 4 Tab + 3 弹层单文件原型，QA 数字自洽回归后定稿。
6. **支付整改（2026-08-29）**：钱包连接 DApp 直接支付取代手动 txid 模式——BSC 为唯一 DApp 支付链（TRC-20 降级过渡）、Indexer 监听 USDT Transfer 自动入账/核验、金额盐→Deposit Registry 合约两级订单绑定、P2P 60min 核验窗口改为 15min 广播窗口、申诉降为兜底。P0（2-3 周）→ P1（合约化 3-4 周）→ P2（Escrow 托管 4-6 周）。
