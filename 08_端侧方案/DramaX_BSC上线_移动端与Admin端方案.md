# DramaX BSC 上线 · 移动端与 Admin 端方案 V1.0

> 决策：只在 BSC 上线（单链）；移动端为 H5 DApp（P0 不做原生 App）；Admin 端支持 owner 登录并上架剧本。
> 依据：《DramaX_钱包支付整改方案_V1.0》《技术架构设计 V1.0》《商业逻辑总结 V2.1》
> 日期：2026-08-29

---

## 1. BSC 单链上线范围（定调）

| 项 | 口径 |
|---|---|
| 支付链 | 仅 BSC 主网，chainId **56** |
| 支付代币 | USDT（BEP-20，`0x55d398326f99059fF775485246999027B3197955`），白名单硬编码 |
| 确认口径 | 15 确认（≈45 秒），Indexer 监听 Transfer 事件自动入账/核验 |
| 钱包 | 移动端：TokenPocket / OKX Wallet / MetaMask 内置浏览器（injected）+ WalletConnect v2 扫码 |
| 登录 | **钱包签名登录为主**（SIWE：nonce + personal_sign 验签换 JWT）；手机号绑定可选（合规 KYC 预留） |
| TRC-20 | 不上线（整改方案中的过渡通道取消——既然 P0 只有 BSC，无需双轨） |
| 合规 | 海外主体 + 中国大陆 IP/身份区域屏蔽（拦截页）不变 |

## 2. 移动端（H5 DApp）

### 2.1 技术口径
- Mobile-first H5，设计基准 **375pt**，桌面打开时居中呈现手机视口容器。
- 单文件原型（HTML+CSS+JS 自包含），与桌面原型同 Design Tokens。
- 钱包交互：`eth_requestAccounts` 连接 → chainId 校验（≠56 引导 `wallet_switchEthereumChain`）→ SIWE 签名登录。

### 2.2 页面清单（4 Tab + 流程页）

| 页面 | 内容 |
|---|---|
| 连接/登录页 | 钱包连接按钮组（TokenPocket/OKX/MetaMask/WalletConnect 扫码）、切链引导、签名登录 |
| 首页 | 资产总览（Drama 余额/生态积分/持仓总值）、今日场次卡（普通区灰底 16:00；创新区紫底 周二/四/六 15:00 与 17:00）、快捷入口 |
| 市场 Tab | P2P 挂单列表、成交记录 |
| 持仓 Tab | 持仓卡（状态机徽标、账面价/增长/占用=增长×85%）、缺口补充（DAO_INSUFFICIENT） |
| 我的 Tab | 团队返佣（1-3 代 7% / 4-10 代 2%）、生态积分明细（来源A/B、1:1）、设置 |
| 支付弹层 | 收款地址 + 金额（含盐值说明）+ gas 预估 → 拉起钱包签名 → 状态页（广播中→确认 x/15→已入账） |

### 2.3 业务数字口径（与桌面原型一致，禁止杜撰）
- 日增长：普通区 2% / 创新区 3%，7 天复利（Pn = P0×(1+r)^n）
- 档位：1,000–5,000→75 / 5,000–12,000→240 / 12,000–35,000→450；300–1,000 标「待确认」
- 增长拆分 70% 手续费 / 15% 现金 / 15% 积分；卖出占用 = 增长×85%；1 Drama = 1 USDT；积分 1:1
- P2P：挂单价 = 账面价×1.03；支付广播窗口 15 分钟
- 合规文案：「历史日增」+ 风险提示绑定出现；禁词（收益/保本/稳赚/回本/零风险/躺赚/翻倍）

## 3. Admin 端（owner 管理后台）

### 3.1 权限模型（P0 最小化）

| 角色 | 权限 |
|---|---|
| **owner** | 全权：剧本上架/下架、场次配置、账务看板、参数设置、管理员管理 |
| staff（只读） | 查询订单/用户/账务（P0 可不开放注册，owner 内部创建） |

- 登录：账号密码（bcrypt）+ 可选 TOTP 2FA；登录失败 5 次锁定 15 分钟；会话 JWT 2h。
- Admin 域名独立（admin.xxx），不进移动端 App 范畴；操作全部落 **audit_log**（who/when/what/before/after）。

### 3.2 功能模块

| 模块 | 功能 |
|---|---|
| **剧本管理（核心）** | 列表（状态筛选：草稿/待审核/已上架/已下架）；新建/编辑剧本（标题、封面、简介、分类、集数、**定价 USDT**、版权存证哈希占位）；**上架/下架操作**（上架前校验：字段完整 + 版权哈希存在） |
| 剧本上架流程 | 草稿 → 待审核 → owner 审核通过 → **已上架（进入场次销售池）** → 可下架；审核意见留痕 |
| 场次管理 | 创建场次（绑定已上架剧本、专区、档位、开抢时间、配额）、场次列表与状态 |
| 订单/持仓查询 | 抢购记录、持仓列表（状态机筛选）、P2P 挂单/撮合监控 |
| 账务看板 | 净入金、手续费收入、返佣支出、积分负债（三生死线指标卡：流动性/积分兑付/财务） |
| 参数设置 | 档位费率、日增长率（只读展示 P0，改动走多签/审计）、区域屏蔽开关 |

### 3.3 Admin 原型口径
- 桌面布局（左侧导航 + 内容区），单文件原型。
- Mock 数据须与业务口径一致（档位表、复利、占用公式、70/15/15）。
- 剧本上架全流程可点通：新建 → 待审核 → 上架（列表状态流转）。
